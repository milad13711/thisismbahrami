# سایت ایستای thisismbahrami.ir

بدون وردپرس، بدون PHP. فایل‌های نهایی در `site/` (در گیت نیست؛ از روی هاست یا ابزارها بازسازی می‌شود). ابزارها در `tools/`.

## انتشار مقاله‌ی جدید

```bash
cd static-site
python3 tools/new_article.py "/مسیر/مقاله.md" \
  --cover "/مسیر/تصویر-شاخص.png" --cover-alt "متن alt تصویر شاخص" \
  --mid "/مسیر/تصویر-میانی.png" --mid-alt "متن alt تصویر میانی" --mid-before "بخشی از عنوان H2 که تصویر قبل از آن بیاید" \
  --link "عبارت=/مسیر-صفحه-مقصد/" --link "عبارت دوم=/مسیر-دیگر/" \
  --dry-run          # اول بدون نوشتن بررسی کن؛ بعد --dry-run را بردار و --deploy بگذار
```

- فایل Markdown باید front matter داشته باشد: `title` (عنوان با عدد)، `metaTitle`، `metaDescription`، `excerpt`، `focusKeyword`، `tags: [..]`، `slug`.
- ابزار: متن را به HTML می‌برد، فلش‌ها را برای راست‌به‌چپ برعکس می‌کند، فهرست مطالب می‌سازد، تصاویر را به WebP تبدیل می‌کند، schema/OG/canonical می‌سازد، به `post-sitemap.xml` اضافه می‌کند، دانشنامه (`/blog/`) و دسته‌ها را دوباره می‌سازد و با `--deploy` فقط فایل‌های تغییرکرده را آپلود می‌کند.
- پیش‌نیاز: `pip3 install markdown pillow` و فایل `~/.netrc` با دسترسی FTP.

## انتشار از پنل ERP (ماژول «وب‌سایت»)

۱. در ERP ماژول «وب‌سایت» را فعال کنید و مقاله را در پنل بنویسید/منتشر کنید.
۲. یک‌بار: در ERP ← تنظیمات ← API یک کلید بسازید و در فایل `~/.thisismbahrami-erp-key` (فقط خود کلید، یک خط، `chmod 600`) بگذارید.
۳. انتشار روی سایت: `python3 tools/sync_from_erp.py` (اول `--dry-run` برای دیدن تغییرها). نوشته‌های تازه/ویرایش‌شده ساخته و فقط فایل‌های تغییرکرده آپلود می‌شود؛ نوشته‌ی «خارج از انتشار» از سایت برداشته و ۴۱۰ می‌شود.
۴. یک‌بار برای ورود مقاله‌های فعلی به ERP: `python3 tools/import_to_erp.py` (مقاله‌های قدیمی با همان HTML کنونی ذخیره می‌شوند و تا وقتی در ERP ویرایش نشوند دوباره ساخته نمی‌شوند).

## ابزارهای دیگر
- `tools/build_hub.py site` — بازسازی دانشنامه و دسته‌ها از روی صفحه‌های مقاله.
- `tools/check_links.py site` — بررسی لینک‌های خراب داخلی.
- `tools/deploy.py <پوشه‌ی-راه-دور> [--only فهرست.txt]` — آپلود با یک اتصال FTP (سرور بعد از چند اتصال هم‌زمان بلاک می‌کند؛ هرگز دو آپلود هم‌زمان اجرا نکنید).
- `tools/crawl.py` و `tools/finalize.py` — فقط برای ساخت اولیه از وردپرس قدیمی بودند.

## نکته‌ها
- آدرس مقاله‌ها بدون تاریخ است (`/نامک/`)؛ همان که گوگل می‌شناسد.
- فرم ارزیابی مستقیم به فرم عمومی ERP می‌فرستد (`t7debc5f8d8e / site-assessment`).
- پایتون این مک گواهی SSL ندارد؛ ابزارها از `/etc/ssl/cert.pem` استفاده می‌کنند.
